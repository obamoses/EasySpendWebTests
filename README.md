 EasySpend Test Automation

 Overview
This project contains end-to-end automated tests for the EasySpend web application, built with Playwright and TypeScript. It follows the Page Object Model (POM) pattern to keep test code readable, maintainable, and easy to extend.

The framework automates the full authentication flow — login, 6-digit OTP verification via Gmail, and 4-digit PIN entry — through to dashboard and Crypto Wallet interactions. Gmail OTP retrieval is handled automatically using the Gmail API, removing the need for any manual intervention during test execution.

Key Features
Page Object Model — page logic and test assertions are cleanly separated
Auto OTP retrieval — Gmail API fetches the OTP email automatically during tests
Auth state reuse — login runs once and saves session state; dashboard tests skip the login flow entirely
Environment-driven — all credentials managed via .env, never hardcoded
CI/CD ready — GitHub Actions pipeline with secrets injection and HTML report artifacts
Headed and headless execution supported

Application Flow
The app follows this sequence, which the automation covers end to end:

Login (/auth/signin)  →  OTP page (6 digits)  →  PIN page (4 digits)  →  Dashboard

From the Dashboard, the Crypto Wallet sidebar item opens a modal with Buy Crypto and Sell Crypto options. Buy Crypto opens WhatsApp in a new tab. Sell Crypto opens a Crypto Funding section where the user selects a coin (USDT).
